<h1 align="center">WallpaperTONS</h1>

<b>Desktop Environment &amp; Taskbar Utility</b>
<br>
<i>An open-source C#/WPF utility for rendering dynamic backgrounds and managing taskbar visual states.</i>

<br>

> **Overview:** WallpaperTONS is an open-source utility that relies on Microsoft Edge WebView2 to parse and render local media files as desktop backgrounds. It also interfaces with the Windows Desktop Window Manager (DWM) to configure taskbar transparency and blur effects.

## Features

<table>
<tr>
<td width="50%" valign="top"><img src="./assets/icon-taskbar.svg" width="48" alt=""><br><b>Taskbar Customization</b><br><sub>Interfaces with Windows DWM to apply visual states (Acrylic, Blur, or Transparency) to the system taskbar.</sub></td>
<td width="50%" valign="top"><img src="./assets/icon-webview.svg" width="48" alt=""><br><b>WebView2 Integration</b><br><sub>Uses the Edge WebView2 runtime to render local video files and JSON-based configurations efficiently.</sub></td>
</tr>
<tr>
<td width="50%" valign="top"><img src="./assets/icon-media.svg" width="48" alt=""><br><b>Local Media Support</b><br><sub>Manages and renders standard high-resolution images and video files stored locally on the user's machine.</sub></td>
<td width="50%" valign="top"><img src="./assets/icon-offline.svg" width="48" alt=""><br><b>Offline Operation</b><br><sub>Functions entirely offline with localized file management, requiring no network telemetry.</sub></td>
</tr>
</table>

## Requirements

| Specification | Minimum Requirement |
| :--- | :--- |
| **Operating System** | Windows 10 (Build 19041+) or Windows 11 |
| **Architecture** | x64 |
| **Memory** | 2 GB RAM |
| **Graphics** | DirectX 12 Compatible GPU |
| **Dependencies** | Microsoft Edge WebView2 Runtime |

## Quick Start

<div align="center">
<img src="./assets/stepper.svg" width="100%" alt="Download, Extract, Launch, Configure">
</div>

1. Navigate to the **[Releases](https://github.com/Project-Tons/WallpaperTONS-App/releases/latest)** section to download the latest compiled executable.
2. Extract the archive to a local directory.
3. Execute the binary to initialize the application.
4. Configure media sources and taskbar states via the provided local interface.
