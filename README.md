<h2 align="center"><img src="https://fonts.gstatic.com/s/e/notoemoji/latest/2728/512.gif" width="32" height="32" align="absmiddle"> Overview</h2>

<p align="center">
<b>WallpaperTONS</b> is an open-source utility that relies on Microsoft Edge WebView2<br>
to parse and render local media files as desktop backgrounds.<br>
It also interfaces with the Windows Desktop Window Manager (DWM)<br>
to configure taskbar transparency and blur effects.
</p>
